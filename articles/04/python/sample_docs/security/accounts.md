# アカウント・PC管理規程

## 第1条 アカウントの発行
社内システムのアカウントは、入社日の前営業日までに情報システム部が発行する。

## 第2条 パスワードを忘れたとき
パスワードを忘れた場合は、セルフサービスポータルから本人がリセットする。多要素認証の端末を失った場合は、情報システム部に連絡する。

## 第3条 ソフトウェアのインストール
会社貸与PCには、許可リストに載っているソフトウェアのみインストールできる。許可リストにないソフトウェアを使いたい場合は、情報システム部に申請する。

## 第4条 PCの交換と返却
会社貸与PCは4年ごとに交換する。退職する社員は、最終出社日までに貸与品をすべて返却する。
