# 情報セキュリティ規程

## 第1条 情報の区分
社内の情報は「極秘」「社外秘」「公開」の3つに区分する。区分が不明な情報は「社外秘」として扱う。

## 第2条 パスワードと多要素認証
パスワードは12文字以上とし、ほかのサービスと使い回してはならない。定期的な変更は求めないが、漏えいのおそれがある場合は直ちに変更する。社内システムへのログインには多要素認証を必須とする。

## 第3条 社外への持ち出し
社外で業務を行う場合は、ディスクが暗号化された会社貸与PCのみを使用する。USBメモリなどの外部記録媒体の使用は禁止する。

## 第4条 紛失・盗難時の報告
会社貸与のPCやスマートフォンを紛失した場合、または盗難にあった場合は、気づいてから1時間以内に情報システム部へ報告する。
