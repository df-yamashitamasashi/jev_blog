# 勤務時間・フレックスタイム規程

## 第1条 標準勤務時間
標準の勤務時間は9時から18時までとし、12時から13時までの60分を休憩時間とする。

## 第2条 フレックスタイム制
全社員にフレックスタイム制を適用する。必ず勤務しなければならないコアタイムは11時から15時まで、始業・終業時刻を選べるフレキシブルタイムは7時から22時までとする。清算期間は1か月とする。

## 第3条 時間外労働
時間外労働を行う場合は、事前に勤怠システムで申請し、所属長の承認を得なければならない。22時から翌5時までの深夜労働は原則として禁止する。

## 第4条 休日
休日は土曜日、日曜日、国民の祝日および年末年始（12月29日から1月3日）とする。
