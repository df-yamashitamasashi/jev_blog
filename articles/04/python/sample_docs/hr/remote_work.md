# 在宅勤務規程

## 第1条 対象者
在宅勤務の対象者は、試用期間を終えた正社員および契約社員とする。

## 第2条 実施日数と申請
在宅勤務は週3日までとする。在宅勤務を行う週の前週金曜日までに勤怠システムで申請し、所属長の承認を得る。

## 第3条 勤務場所
在宅勤務は、会社に届け出た自宅で行う。カフェなど不特定多数が出入りする場所での業務は禁止する。ただし、会社が契約したサテライトオフィスは利用できる。

## 第4条 在宅勤務手当
在宅勤務を月4日以上行った月は、通信費・光熱費の補助として在宅勤務手当5,000円を給与に加算して支給する。

## 第5条 貸与品
業務に必要なノートPC1台と外付けディスプレイ1台を会社が貸与する。
