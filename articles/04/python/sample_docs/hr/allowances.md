# 給与・諸手当規程

## 第1条 給与の支給日
給与は毎月25日に支給する。支給日が休日にあたる場合は、その直前の営業日に支給する。

## 第2条 通勤手当
公共交通機関を利用して通勤する社員には、最も経済的かつ合理的な経路の定期券代を通勤手当として支給する。支給額は月50,000円を上限とする。

## 第3条 住宅手当
世帯主である社員に、住宅手当として月20,000円を支給する。

## 第4条 家族手当
扶養する配偶者がいる社員には月10,000円、扶養する子1人につき月5,000円を家族手当として支給する。
