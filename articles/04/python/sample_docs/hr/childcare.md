# 育児・介護休業規程

## 第1条 育児休業
社員は、子が1歳になるまでの間、育児休業を取得できる。保育所に入れないなどの事情がある場合は、最長で子が2歳になるまで延長できる。

## 第2条 出生時育児休業（産後パパ育休）
子の出生後8週間以内に、最大28日の出生時育児休業を取得できる。2回まで分割して取得できる。

## 第3条 介護休業
要介護状態にある対象家族1人につき、通算93日まで介護休業を取得できる。3回まで分割して取得できる。

## 第4条 子の看護休暇
小学校入学前の子を養育する社員は、子の看護のため、子が1人の場合は年5日、2人以上の場合は年10日の看護休暇を取得できる。
