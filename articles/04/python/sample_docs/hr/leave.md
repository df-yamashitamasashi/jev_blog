# 休暇規程

## 第1条 年次有給休暇の付与
入社日から6か月間継続勤務し、所定労働日の8割以上出勤した社員には、10日の年次有給休暇を付与する。その後は1年ごとに勤続年数に応じて付与日数を増やし、勤続6年6か月以上で年20日を上限とする。

## 第2条 取得単位
年次有給休暇は1日単位のほか、半日単位（年10回まで）および時間単位（年5日分まで）で取得できる。

## 第3条 取得の申請
年次有給休暇を取得するときは、原則として取得日の3営業日前までに勤怠システムで申請し、所属長の承認を得る。急病などやむを得ない場合は、事後の申請を認める。

## 第4条 年次有給休暇の繰り越し
当年度に使い切れなかった年次有給休暇は、翌年度に限り繰り越すことができる。繰り越せる日数の上限は20日とし、繰り越し分と当年度付与分を合わせて保有できる日数は最大40日とする。上限を超えた日数は消滅する。

## 第5条 特別休暇
会社は、年次有給休暇とは別に、次の特別休暇を有給で付与する。
- 夏季休暇：毎年7月から9月の間に3日
- 結婚休暇：本人が結婚したとき5日（入籍日から6か月以内に取得）
- 配偶者出産休暇：配偶者が出産したとき3日
- 忌引休暇：配偶者・父母・子が亡くなったとき5日、祖父母・兄弟姉妹が亡くなったとき2日

特別休暇は翌年度に繰り越すことはできない。
