# 国内出張旅費規程

## 第1条 適用範囲
この規程は国内出張に適用する。出張とは、勤務地から片道100km以上の移動、または宿泊を伴う業務上の移動をいう。

## 第2条 日当
出張中の食事代などの補助として、日帰り出張は1日2,000円、宿泊を伴う出張は1日3,000円の日当を支給する。

## 第3条 宿泊費
宿泊費は実費を支給する。1泊あたりの上限は、東京23区・大阪市・名古屋市が12,000円、その他の地域が10,000円とする。

## 第4条 交通機関
新幹線は普通車指定席を利用する。グリーン車は部長以上に限り利用できる。航空機は片道500km以上の移動に限り利用できる。
