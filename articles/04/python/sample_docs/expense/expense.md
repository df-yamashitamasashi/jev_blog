# 経費精算規程

## 第1条 申請期限
経費は、支出が発生した月の翌月10日までに経費精算システムで申請する。期限を過ぎた申請は、所属長の理由書がある場合に限り受け付ける。

## 第2条 領収書
申請には領収書を添付する。紙の領収書はスマートフォンで撮影した画像を添付すれば、原本の提出は不要とする。

## 第3条 事前申請
1件10,000円以上の支出は、支出の前に所属長の承認を得なければならない。

## 第4条 接待交際費
取引先との会食費は、参加者1人あたり5,000円までとする。これを超える場合は、事前に部長の承認を得る。

## 第5条 精算額の支払い
毎月末に締めて承認された精算額は、翌月25日の給与と合わせて支払う。
