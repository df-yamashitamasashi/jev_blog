# SampleCloud API 認証仕様

## 認証方式
SampleCloud API は、APIキーと OAuth 2.0（クライアントクレデンシャルズフロー）の2つの認証方式に対応する。

## アクセストークン
OAuth 2.0 で発行されるアクセストークンの有効期限は1時間である。期限切れのトークンでリクエストすると HTTP 401 が返る。

## リフレッシュトークン
リフレッシュトークンの有効期限は30日である。/v1/oauth/token にリフレッシュトークンを送ると、新しいアクセストークンを取得できる。

## APIキーのローテーション
APIキーは1つのプロジェクトにつき最大2本まで同時に有効にできる。新しいキーを発行してから古いキーを無効化することで、停止せずにキーを切り替えられる。
