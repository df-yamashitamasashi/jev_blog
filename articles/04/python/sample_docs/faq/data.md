# SampleCloud FAQ：データの管理

## データをエクスポートできますか？
管理者アカウントから、いつでも CSV または JSON 形式で全データをエクスポートできます。

## 解約後のデータはどうなりますか？
解約から30日後に、すべてのデータを完全に削除します。削除後の復元はできません。

## バックアップはありますか？
データは毎日バックアップし、7日間保存しています。

## データはどこに保存されていますか？
東京リージョンのデータセンターに保存しています。災害対策として、大阪リージョンにも複製しています。
