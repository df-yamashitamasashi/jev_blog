# SampleCloud FAQ：契約・解約

## 解約はいつまでに申し込めばよいですか？
契約更新日の7日前までに、管理画面の「プラン設定」から解約を申し込んでください。

## 年払いプランを途中で解約したら返金されますか？
年払いプランを途中で解約した場合でも、残りの期間分の返金は行っていません。契約期間の終了日まではすべての機能を利用できます。

## 解約すると違約金はかかりますか？
違約金はかかりません。

## プランを下位プランに変更するとどうなりますか？
下位プランへの変更は、次回の契約更新日から適用されます。上位プランへの変更は即時に適用され、差額は日割りで請求します。
